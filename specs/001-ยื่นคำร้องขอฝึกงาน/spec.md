# Feature: ยื่นคำร้องขอฝึกงาน (Internship Application Submission)   Source: UC-02
Status: Draft v2
Last Updated: 2026-09-23

## Goal
นักศึกษาสามารถเลือกสถานประกอบการ/ตำแหน่งงาน กรอกข้อมูลพร้อมแนบเอกสาร และยื่นคำร้องขอฝึกงานได้อย่างถูกต้อง ครบถ้วน และได้รับการแจ้งเตือนสถานะอย่างรวดเร็ว

## Scope
- In: เลือกตำแหน่งงานฝึกงาน | กรอกข้อมูล + แนบเอกสาร | เพิ่มสถานประกอบการใหม่ (กรณีไม่มีในระบบ) | ยืนยันส่งคำร้อง | แจ้งเตือนอาจารย์ที่ปรึกษา
- Out: การพิจารณา/อนุมัติคำร้องของอาจารย์ (UC ถัดไป) | การประเมินผลฝึกงาน | การยืนยันตัวตนเข้าสู่ระบบ (UC-09)

## Constraints
- PRE-01 นักศึกษาต้องผ่านการยืนยันตัวตน (UC-09) และมีสถานะวิชาฝึกงานพร้อมลงทะเบียน โดยตรวจสอบผ่าน API กับระบบทะเบียนกลางจากเงื่อนไข: ผ่านรายวิชาบังคับก่อน (Prerequisite) และมีสถานะทางการศึกษาปกติ (Active)
- NFR-SEC-01 ไฟล์เอกสารที่อัปโหลดต้องได้รับการสแกนไวรัสและจัดเก็บในระบบที่เข้ารหัส

## Requirements
- FR-UC02-01 ระบบต้องให้นักศึกษาค้นหาและเลือกตำแหน่งงานฝึกงานที่ต้องการยื่นคำร้อง
- FR-UC02-02 ระบบต้องแสดงแบบฟอร์มการยื่นคำร้องพร้อมข้อมูลส่วนตัวของนักศึกษาโดยอัตโนมัติ
- FR-UC02-03 ระบบต้องให้นักศึกษากรอกข้อมูลสถานประกอบการ ชื่อพี่เลี้ยง และอัปโหลดไฟล์ Resume/Transcript เป็นไฟล์ PDF อย่างละ 1 ไฟล์ (Resume 1 ไฟล์ + Transcript 1 ไฟล์) โดยขนาดรวมกันไม่เกิน 10MB
- FR-UC02-04 หากสถานประกอบการที่เลือกไม่มีในระบบ ระบบต้องเปิดแบบฟอร์มเพิ่มข้อมูลสถานประกอบการใหม่ แล้วกลับไปยังขั้นตอนกรอกข้อมูล (FR-UC02-03) โดยบันทึกข้อมูลดังกล่าวเป็น Draft State สำหรับคำร้องนั้นๆ และติด Flag ให้เจ้าหน้าที่ฝึกงานตรวจสอบความถูกต้องย้อนหลัง
- FR-UC02-05 ระบบต้องแสดงหน้าสรุปข้อมูลคำร้องและข้อตกลงการฝึกงานก่อนให้นักศึกษายืนยัน โดยต้องมี Checkbox บังคับให้กดตกลงก่อนเปิดปุ่ม "ยืนยันส่งคำร้อง"
- FR-UC02-06 เมื่อนักศึกษากดยืนยัน ระบบต้องบันทึกข้อมูลคำร้อง เปลี่ยนสถานะเป็น "รอการอนุมัติ" และส่งข้อความแจ้งเตือนไปยังอาจารย์ที่ปรึกษาหลักเพียง 1 คน จากข้อมูลโปรไฟล์นักศึกษาในระบบทะเบียนกลาง (Registration System)
- FR-UC02-07 หากไฟล์เอกสารที่แนบมีขนาดเกิน 10MB หรือพบว่าไฟล์มีความเสี่ยงไม่ปลอดภัย ระบบต้องไม่อนุญาตให้กดยืนยันคำร้อง พร้อมแสดงข้อความแจ้งเตือนสาเหตุ และให้เลือกไฟล์ใหม่
- FR-UC02-08 หากระบบไม่สามารถส่ง notification ได้ ระบบต้องยังคงบันทึกข้อมูลคำร้องไว้ และตั้งคิวส่งข้อความแจ้งเตือนใหม่อัตโนมัติทุก 1 นาที สูงสุด 5 ครั้ง ภายใน 5 นาที หากไม่สำเร็จให้บันทึก Error Log สำหรับ Developer โดยไม่ต้องแจ้งนักศึกษา

## Quality Requirements
- NFR-UC02-01 (NFR-PERF-01) ขั้นตอนบันทึกคำร้อง (FR-UC02-06) ต้องประมวลผลและแสดงผลการบันทึกสำเร็จภายใน 3 วินาที
- NFR-UC02-02 (NFR-SEC-01) ไฟล์เอกสารที่อัปโหลดทุกไฟล์ต้องผ่านการสแกนไวรัสและจัดเก็บในระบบที่เข้ารหัสก่อนบันทึกคำร้องสำเร็จ

## Acceptance Criteria
- [ ] AC-UC02-01 (FR-UC02-01,02,03,05,06)
      Given นักศึกษาเข้าสู่ระบบแล้วและมีสถานะพร้อมฝึกงาน
      When นักศึกษาเลือกตำแหน่งงาน กรอกข้อมูลคำร้องครบถ้วน และกด "ยืนยัน"
      Then ระบบต้องบันทึกคำร้องสำเร็จ เปลี่ยนสถานะเป็น "รอการอนุมัติ" และส่งการแจ้งเตือนไปยังอาจารย์ที่ปรึกษาสำเร็จ ภายใน 3 วินาที
- [ ] AC-UC02-02 (FR-UC02-04)
      Given นักศึกษากำลังกรอกแบบฟอร์มคำร้อง
      When นักศึกษาเลือกสถานประกอบการที่ไม่มีอยู่ในระบบ
      Then ระบบต้องเปิดแบบฟอร์มเพิ่มข้อมูลสถานประกอบการใหม่ และกลับไปยังขั้นตอนกรอกข้อมูลคำร้องเมื่อบันทึกเสร็จ
- [ ] AC-UC02-03 (FR-UC02-07, NFR-UC02-02)
      Given นักศึกษากำลังแนบไฟล์ Resume/Transcript
      When ไฟล์ที่เลือกมีขนาดเกิน 10MB
      Then ระบบต้องแสดงข้อความแจ้งเตือน "ไฟล์มีขนาดเกิน 10MB" และให้นักศึกษาเลือกไฟล์ใหม่ โดยไม่บันทึกคำร้อง
- [ ] AC-UC02-04 (FR-UC02-08)
      Given คำร้องของนักศึกษาถูกบันทึกในระบบแล้ว
      When ระบบไม่สามารถส่ง notification ไปยังอาจารย์ที่ปรึกษาได้ในทันที
      Then ระบบต้องยังคงบันทึกข้อมูลคำร้องไว้ และตั้งคิวส่งข้อความแจ้งเตือนใหม่อัตโนมัติให้สำเร็จภายใน 5 นาที

## Assumptions
- ASM-01 อาจารย์ที่ปรึกษาที่ได้รับการแจ้งเตือนคืออาจารย์ที่ปรึกษาหลักเพียง 1 คน โดยเลือกจากข้อมูลโปรไฟล์นักศึกษาในระบบทะเบียนกลาง
- ASM-02 เมื่อนักศึกษากรอกสถานประกอบการใหม่ ระบบบันทึกข้อมูลดังกล่าวไว้เป็น Draft State สำหรับคำร้องนั้นๆ และติด Flag ให้เจ้าหน้าที่ฝึกงานตรวจสอบความถูกต้องย้อนหลัง
- ASM-03 การตรวจสอบสถานะวิชาฝึกงานพร้อมลงทะเบียนทำผ่าน API เชื่อมต่อกับระบบทะเบียนกลาง โดยเช็กจากเงื่อนไข: ผ่านรายวิชาบังคับก่อน (Prerequisite) และมีสถานะทางการศึกษาปกติ (Active)
- ASM-04 นักศึกษาสามารถยื่นคำร้องขอฝึกงานได้เพียง 1 คำร้อง ต่อ 1 ภาคการศึกษา หากต้องการเปลี่ยนตำแหน่งต้องยกเลิกคำร้องเดิมที่รออนุมัติก่อน
- ASM-05 ไฟล์ที่อัปโหลดอนุญาตเฉพาะนามสกุล .pdf และแยกเป็น 2 ช่องอัปโหลด คือ Resume 1 ไฟล์ + Transcript 1 ไฟล์ โดยขนาดรวมกันไม่เกิน 10MB
- ASM-06 หากไฟล์เกิน 10MB หรือพบไฟล์ไม่ปลอดภัย ระบบจะ Block การกดยืนยันคำร้อง พร้อมแสดง Message แจ้งเตือนสาเหตุเพื่อให้นักศึกษาเปลี่ยนไฟล์ใหม่ก่อนส่ง
- ASM-07 หากการส่ง notification ล้มเหลว ระบบจะ Retry ทุก 1 นาที สูงสุด 5 ครั้ง ภายใน 5 นาที และบันทึก Error Log สำหรับ Developer โดยคำร้องจะยังคงส่งสำเร็จตามปกติและไม่ต้องแจ้งนักศึกษา
- ASM-08 ก่อนปุ่ม "ยืนยันส่งคำร้อง" จะเปิดใช้งานได้ ต้องมี Checkbox บังคับให้กดตกลงว่า “ข้าพเจ้าขอรับรองว่าข้อมูลข้างต้นเป็นความจริงทุกประการ”

## Open Questions
- ไม่มี Open Questions ที่ค้างอยู่หลังจากตอบคำถาม 8 ข้อแล้ว
